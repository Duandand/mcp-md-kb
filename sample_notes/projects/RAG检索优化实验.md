# RAG 检索优化实验记录

## 实验设计
- 基线：单路向量检索（bge-large-zh）+ Top5 直通；
- 实验组：Query 改写 + 混合检索（BM25 + 向量）+ 精排。

## 结果
| 指标 | 基线 | 实验组 |
|---|---|---|
| Top5 命中率 | 71.2% | 86.5% |
| MRR | 0.58 | 0.74 |
| P95 时延 | 190ms | 340ms |

## 结论
1. Query 改写对口语化长问题收益最大，单独贡献 +6.3% 命中率；
2. 难负样本挖掘后精排收益显著，但精排模型时延需要用蒸馏压缩；
3. 下一步验证分级截断策略，控制送入大模型的上下文长度在 4K 以内。
